1. Що змінилося у виводі git status після git add?

Відповідь: Файли перемістилися з червоного списку невідстежуваних чи змінених до зеленого списку індексу (Changes to be committed), що означає їхню готовність до збереження (коміту).

2. Що показує git diff?

Відповідь: Ця команда показує детальні зміни, які були зроблені у файлах, але ще не додані в індекс.

3. Чим відрізняється git switch main від git merge?

Відповідь: Команда git switch main просто перемикає активну робочу гілку на гілку main, тоді як git merge зливає (об'єднує) історію та зміни з іншої гілки в поточну.

4. Чому виник конфлікт і як ти його розв'язав?

Відповідь: Конфлікт виник через те, що в різних гілках (main та ukr-title) був змінений один і той самий рядок коду в файлі index.html. Я розв'язав його вручну: відкрив файл, видалив службові символи Git  і залишив правильний варіант тексту.
